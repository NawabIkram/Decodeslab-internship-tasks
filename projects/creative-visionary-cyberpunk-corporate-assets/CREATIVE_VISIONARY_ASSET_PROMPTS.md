# NEXORA Cyberpunk-Corporate Visual Asset Pack

## Brand Direction

Fictional startup: **NEXORA**

Visual style: premium cyberpunk-corporate, futuristic but restrained.  
Core motif: a transparent glowing prism/cube with angular N-inspired geometry.  
Palette: graphite black, electric cyan, magenta accents, brushed silver, clear glass.  
Lighting: low-key studio light, cyan rim glow, magenta inner glow, polished reflections.

## Prompt 1: Logo Concept

Create a high-fidelity cyberpunk-corporate logo concept for a fictional tech startup named "NEXORA". Combine a sleek angular N monogram with a glowing prism/cube motif, suggesting AI infrastructure, secure networks, and future enterprise technology. Use a premium vector-inspired brand mark with polished 3D metallic edges, clean corporate identity, centered square composition, logo mark above a small readable wordmark, deep graphite black, electric cyan, magenta accents, and brushed silver highlights.

Negative prompt: avoid generic stock tech logo, clipart, messy gradients, extra text, watermark, low resolution, distorted letters, illegible typography, overly playful style.

Aspect ratio: 1:1

## Prompt 2: Website Hero

Create a cinematic cyberpunk-corporate hero image for NEXORA, using the same glowing prism/cube motif and angular N visual language from the logo concept. Show a premium futuristic boardroom overlooking a neon smart city, with a transparent holographic prism/cube floating above a dark conference table, projecting clean data streams and network lines. Use a wide composition with open negative space on the left for website copy. Lighting should be blue hour city light, cyan rim light, magenta accent reflections, and soft volumetric glow.

Negative prompt: avoid stock photo feeling, people posing, cluttered dashboards, excessive sci-fi chaos, illegible text, watermark, logo duplication, distorted objects.

Aspect ratio: 16:9

## Prompt 3: Icon Set

Create a unified icon set of five premium icons for NEXORA: AI Core, Secure Cloud, Data Mesh, Automation, Analytics. Each icon should be built around the same glowing angular prism/cube motif and thin-line corporate geometry. Use vector-inspired 3D icons, clean isometric style, dark graphite background, electric cyan lines, magenta nodes, and brushed silver surfaces. Arrange the icons in a neat horizontal row with equal spacing and consistent perspective.

Negative prompt: avoid random mismatched icons, cartoon style, flat generic clipart, excessive detail, text, watermark, clutter, low resolution.

Aspect ratio: 16:9

## Prompt 4: Social AI Core Scene

Create a square cyberpunk-corporate social visual for NEXORA featuring the same glowing prism/cube brand object translated into a different scene: a compact executive AI device sitting on a matte black desk beside a glass tablet and secure access card. Use realistic reflections, shallow depth of field, low-key studio lighting, cyan rim light, magenta underglow, and a blurred neon corporate city background.

Negative prompt: avoid messy desk clutter, handwritten notes, generic stock laptop, people, watermark, extra logos, distorted object.

Aspect ratio: 1:1

## Prompt 5: Vertical Story Visual

Create a vertical cyberpunk-corporate campaign visual for NEXORA showing the same transparent glowing prism/cube AI core translated into a secure data corridor scene. The prism/cube floats in the foreground while streams of clean light paths flow into a distant corporate skyline. Use sleek glass panels, silver floor reflections, dramatic cyan rim lights, magenta accents, subtle volumetric haze, and strong upward perspective lines.

Negative prompt: avoid chaotic cyberpunk street, grunge, graffiti, unreadable UI text, generic stock photo, watermark, distorted cube, random extra logos.

Aspect ratio: 9:16

## Image-to-Image Consistency Method

To keep the set consistent, every prompt repeats the same identity anchors:

- transparent glowing prism/cube object
- angular N-inspired geometry
- cyan neon edges
- magenta internal glow
- graphite, silver, and glass materials
- polished corporate lighting

This simulates image-to-image translation by preserving the same object identity while placing it in different scenes: logo, hero banner, icon system, product-style social post, and vertical campaign visual.
